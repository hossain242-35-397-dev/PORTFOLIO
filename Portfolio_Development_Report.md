## 1. Introduction & Executive Summary
This report outlines the planning, execution, design strategy, and deployment process of my personal portfolio website. The primary objective of this project was to construct a responsive, visually aesthetic, cyber-security-themed personal portfolio to showcase my academic journey, software engineering projects, technical skills, and contact profiles.

---

## 2. Planning & Design Strategy
### 2.1 Aesthetic Theme & Visual Concept
As a Software Engineering student aspiring to be a Cyber Security Professional, I chose a **Dark Cyberpunk / Tech Security** visual theme:
- **Color Palette:** Deep Void Black (`#0b0f19`), Electric Cyan (`#00f0ff`), Neon Violet (`#7000ff`), and Muted Slate (`#94a3b8`).
- **Typography:** Inter (for clean body readability) paired with Fira Code (monospaced font for code-like tech elements).
- **Layout:** Glassmorphic navigation bar, glowing CSS borders, and animated cards to provide a high-end, aesthetic modern UI.

### 2.2 Wireframe Structure
1. **Header / Navigation:** Logo with mono-space code syntax, navigation links to sections.
2. **Hero Section:** Introduction, security badge, quick call-to-action buttons.
3. **Skills Section:** Visual grid containing core programming languages and tools (HTML, CSS, JS, Python, C++, Git).
4. **Projects Section:** Dynamic project cards featuring *Garage Management System* and *Smart Face Recognition Attendance System (SFRA)*.
5. **Education Section:** Timeline layout highlighting academic progression.
6. **Contact Section:** Glassmorphic callout box with interactive social icons.

---

## 3. Technologies & Development Process
### 3.1 Tech Stack Used
- **HTML5:** Semantic structuring (`<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Custom CSS Variables, Flexbox, Grid layout, Glassmorphism backdrop-blur effects, and responsive `@media` queries.
- **FontAwesome & Google Fonts:** Vector icon set and modern typography.
- **Git & GitHub:** Version control and hosting via GitHub Pages.
